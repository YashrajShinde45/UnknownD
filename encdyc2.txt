Experiment: Data Encryption and Decryption of a File Using Python
Aim: To encrypt a file so that nobody can read it without a key, and then decrypt it to get the original file back.
Step 1: Install Python Library
Open CMD and run:
pip install cryptography
python -m pip install cryptography


Step 2: Create a Python File
1. Create a folder named Encryption.
2. Inside it, create a file named encryption.py.
3. Create a text file named message.txt and write some text in it.
Step 3: Write This Code
from cryptography.fernet import Fernet

# Generate an encryption key
key = Fernet.generate_key()

# Save the key
with open("secret.key", "wb") as file:
    file.write(key)

# Read the key
fernet = Fernet(key)

# Read original file
with open("message.txt", "rb") as file:
    data = file.read()

# Encrypt the file
encrypted_data = fernet.encrypt(data)

with open("encrypted.txt", "wb") as file:
    file.write(encrypted_data)

print("File Encrypted Successfully!")

# Decrypt the file
decrypted_data = fernet.decrypt(encrypted_data)

with open("decrypted.txt", "wb") as file:
    file.write(decrypted_data)

print("File Decrypted Successfully!")


Step 4: Execute the Program
Open CMD in the Encryption folder and run:
python encryption.py


Step 5: Check the Output
Expected output
File Encrypted Successfully!
File Decrypted Successfully!


Your folder will contain:
- message.txt – Original readable file.
- secret.key – Secret encryption key.
- encrypted.txt – Encrypted unreadable data.
- decrypted.txt – Original text after decryption.



Important: Keep secret.key safe. Without this key, you cannot decrypt the encrypted file.
Result
Successfully implemented file encryption and decryption using Python.

Part 1: Install and run OpenVAS using Docker Desktop
Step 1: Check Docker Desktop
1. Open Docker Desktop.
2. Wait until Docker Engine is running.
3. Make sure Docker is using Linux containers.
4. Open CMD or PowerShell.
Check Docker:
docker --version
docker compose version


If both commands show version numbers, Docker is ready.
Step 2: Create an OpenVAS folder
Open CMD and execute:
mkdir C:\OpenVAS
cd C:\OpenVAS


Step 3: Download the OpenVAS configuration file
Run this command in PowerShell:
Invoke-WebRequest -Uri "https://greenbone.github.io/docs/latest/_static/compose.yaml" -OutFile "compose.yaml"


This downloads the official Greenbone Docker Compose file. It starts multiple containers required for OpenVAS. 
Greenbone Community Documentation


Check that the file exists:
dir


You should see:
compose.yaml


Step 4: Download OpenVAS containers
Run:
docker compose pull

Wait for the images to download. This can take some time because OpenVAS uses multiple containers.
Step 5: Start OpenVAS
Run:
docker compose up -d


This starts the OpenVAS services in the background.

Check the containers:
docker compose ps

You should see several Greenbone containers. Some data containers may exit after successfully copying their data; that is normal.
Step 6: Set the admin password
Run this command and replace YourPassword123 with your own password:
docker compose exec -u gvmd gvmd gvmd --user=admin --new-password='YourPassword123'


Your login details will be:
- Username: admin
- Password: Your chosen password
Step 7: Open OpenVAS in your browser
Open Chrome and visit:
Open Greenbone Security Assistant







beafn28.gitbook.io


If Chrome displays a certificate warning, it is because the local installation uses a self-signed certificate. Continue only to your own local OpenVAS installation.

Login using your admin credentials.

Wait for the vulnerability feeds to finish loading before scanning. Initial feed synchronization can take a long time, sometimes hours. Scans may give incomplete results until the feeds are ready. 
Greenbone Community Documentation+1
